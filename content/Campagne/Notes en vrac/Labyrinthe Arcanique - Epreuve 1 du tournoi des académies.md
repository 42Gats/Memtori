
## Fonctionnement général

- **6 équipes** participent :
    - Équipe des joueurs
    - Académie de l’Évocation
    - Académie de l’Altération
    - Académie de l’Influence
    - Académie des Arcanes
    - Académie de l’Ingénierie Arcanique
- Les équipes parcourent un immense labyrinthe magique.
- Le labyrinthe est composé de salles reliées entre elles.
- Les équipes peuvent se croiser, s'entraider ou se gêner.
- Les affrontements directs sont interdits.
- Certaines salles donnent des **points bonus**, d'autres peuvent en faire perdre.
- Les deux équipes ayant le moins de points à la sortie sont éliminées.

### Score conseillé

| Événement                        |     Points |
| -------------------------------- | ---------: |
| Résolution rapide d'une énigme   |        +15 |
| Résolution normale               |        +10 |
| Bonus optionnel                  |   +5 à +10 |
| Échec d'une épreuve              |         -5 |
| Piège important                  |         -5 |

# 1. Salle des Miroirs

### Principe

Une immense salle circulaire contient une dizaine de miroirs identiques.

Lorsque l'équipe tente de traverser un miroir :

> Le personnage touche la surface du miroir et disparaît à l'intérieur.  
> Une seconde plus tard, il ressort d'un autre miroir situé à l'opposé de la salle.

Peu importe le miroir utilisé, le résultat est toujours identique.

Les joueurs sont donc **enfermés dans une boucle**.

### Rencontre

Une autre équipe est déjà présente. Celle de l'ingénieurie arcanique

Elle a visiblement essayé plusieurs solutions.

> « On a essayé tous les miroirs.  
> Celui-là, celui-là, même celui derrière nous.  
> On revient toujours ici. »

L'autre équipe peut être utilisée comme aide ou comme élément de pression.

### Indice

Sur le sol, presque invisible, se trouve une inscription :

> **« Les illusions ne trompent que ceux qui utilisent leurs yeux pour voir. »**

Les miroirs ne sont pas réellement des portes.

Ils reflètent la salle, mais **un seul élément de chaque reflet est différent**.

Les joueurs doivent observer les reflets.

### Solution

Tous les miroirs reflètent la salle a l'identique sauf un où un élément est légérement différent.

### Manipulation

Pour activer le miroir :

1. Les joueurs doivent identifier le miroir différent.
2. Ils doivent tous se placer devant celui-ci.
3. Une personne doit **cesser de regarder son reflet** et fermer les yeux.
4. Elle doit ensuite traverser le miroir

### Variante

Si les joueurs comprennent que les miroirs fonctionnent en boucle mais ne trouvent pas la solution, l'autre équipe peut alors les aider.

### Récompense
- **+10 points** si l'équipe trouve seule la solution.
- +5 points pour l'autre équipe qui n'a pas trouver la solution

# 2. Le Mur Vivant

### Principe

Un long couloir se termine sur un mur couvert de veines rouges.

Lorsqu'un joueur s'approche, le mur bouge.

Une bouche apparaît.

> **« Je ne vous laisserai passer que si vous me nourrissez. »**

Le mur attaque toute personne qui tente de le traverser.

### Indice

Sur le sol se trouvent plusieurs objets :

- une pierre ;
- une pièce d'or ;
- une plante ;
- une plume.

Au-dessus :

> **« Ce qui vit doit donner ce qu'il possède.  
> Ce qui est mort ne peut nourrir le vivant. »**

### Solution

Le mur ne veut pas être nourri avec quelque chose de précieux.

Il veut quelque chose **qui est vivant**.

Les joueurs doivent donc donner :

- une plante vivante ;
- une petite quantité de sang ;
- ou tout autre élément clairement vivant.

Le mur absorbe alors l'offrande et s'ouvre.

### Manipulation

Une simple goutte de sang suffit.

Un joueur peut se couper légèrement la main et poser celle-ci contre le mur.

Le mur absorbe le sang.

> Les veines rouges s'illuminent.  
> Le mur se contracte lentement avant de s'ouvrir comme une membrane.

### Mauvaises solutions

Si les joueurs donnent :

- une pièce ;
- une pierre ;
- un objet magique ;
- un cadavre ;

le mur refuse.

S'ils forcent le passage, il provoque une attaque ou un petit combat.

### Récompense

- **+10 points** si résolu sans violence.
- **-5 point** si le mur est forcé.

# 3. Épreuve de Confiance

Deux équipes arrivent simultanément dans une pièce. les joueurs et l'équipe de l'académie de l'influence.

Elles sont séparées par un immense mur.

Chaque équipe dispose de deux boutons :

🔴 **Rouge**  
🟢 **Vert**

Une inscription explique les règles.

> **« Votre choix ne dépend pas de vous seuls. »**

### Règles

| Équipe A | Équipe B | Résultat  |
| -------- | -------- | --------- |
| Rouge    | Rouge    | -10 / -10 |
| Rouge    | Vert     | +20 / -20 |
| Vert     | Rouge    | -20 / +20 |
| Vert     | Vert     | +10 / +10 |

Les équipes disposent de **30 secondes** pour choisir.

### Intérêt

Les joueurs peuvent entendre l'autre équipe derrière le mur.

Ils peuvent donc :

- négocier ;
- mentir ;
- promettre de choisir vert ;
- tenter de convaincre l'autre équipe.

Mais ils ne peuvent pas savoir avec certitude ce qu'elle va faire.

### Variante intéressante

Le bouton ne peut être pressé qu'une seule fois.

Une fois choisi, impossible de changer.

### Mise en scène

Après le choix :

> Un énorme gong résonne.

Puis les portes s'ouvrent.

Les deux équipes découvrent immédiatement le résultat.

# 4. Salle de l'Altération — La Salle Impossible

### Apparence

La pièce semble totalement normale.

Puis les joueurs avancent.

Le sol devient un mur.

Le plafond devient le sol.

Une porte apparaît à 30 mètres alors qu'elle était juste devant eux.

La gravité change régulièrement.

### Rencontre

L'équipe de l'Altération est déjà là.

Elle semble parfaitement à l'aise.

Un étudiant marche tranquillement sur un mur.

> « Vous finirez par vous habituer. Enfin... probablement. »

### Épreuve

Les joueurs doivent atteindre une porte située à l'autre bout.

Toutes les **20 secondes**, la pièce change :

1. Gravité normale.
2. Gravité vers le mur gauche.
3. Gravité vers le plafond.
4. Gravité vers le mur droit.
5. Gravité inversée.

### Solution

Il ne faut pas lutter contre la pièce.

Des symboles apparaissent brièvement avant chaque changement de gravité.

Ils indiquent **où la prochaine gravité va s'appliquer**.

Les joueurs peuvent donc anticiper le mouvement.

### Récompense

- Traversée : **+10**
- Chute / erreur : **-5**

# 5. Salle des Arcanes — La Bibliothèque Interdite

### Apparence

Une immense bibliothèque bloque le passage.

Des milliers de livres sont présents.

Au milieu se trouve une porte.

Sur celle-ci :

> **« La connaissance ouvre les portes.  
> Mais seule la bonne connaissance ouvre celle-ci. »**

### Épreuve

Trois livres sont posés sur un pupitre :

- _Les Plans et leurs frontières_
- _Les Grandes Batailles de l'Est_
- _Principes fondamentaux de l'Alchimie_

À côté se trouvent trois symboles :

- une sphère ;
- une épée ;
- une fiole.

Les joueurs doivent associer correctement les livres aux symboles.

### Twist

Les titres sont volontairement trompeurs.

Le bon livre est déterminé par **le contenu**, pas par le titre.

### Livre 1 — _Les Plans et leurs frontières_

Le titre laisse penser qu'il s'agit uniquement d'un ouvrage sur les plans.

En réalité, le livre commence par une longue partie historique expliquant **les guerres provoquées par les premières incursions planaires**.

Un passage important raconte notamment :

> « Lorsque les frontières entre les mondes commencèrent à se fissurer, les royaumes ne cherchèrent pas à comprendre le phénomène. Ils cherchèrent d'abord à le combattre. »

Le livre contient donc une importante partie consacrée aux **conflits**.

➡️ **Ce livre va avec ⚔️ l'Épée.**

### Livre 2 — _Les Grandes Batailles de l'Est_

Le titre fait penser à un simple livre historique sur la guerre.

Mais lorsqu'on le consulte, les joueurs découvrent que l'auteur est en réalité un **chercheur en magie** qui analyse les armes et techniques utilisées pendant ces batailles.

Une grande partie du livre explique comment certaines armées utilisaient :

- des potions ;
- des poisons ;
- des poudres explosives ;
- des élixirs de soin ;
- des substances permettant de résister à certains sorts.

Un chapitre entier s'intitule :

> **« L'alchimie militaire et ses conséquences »**

➡️ **Ce livre va avec ⚗️ la Fiole.**

### Livre 3 — _Principes fondamentaux de l'Alchimie_

C'est celui qui paraît le plus évident.

Pourtant, en lisant l'introduction, les joueurs découvrent que l'auteur explique que **l'alchimie n'est pas seulement la transformation de la matière**.

Elle est utilisée pour comprendre les différences entre les matières provenant des différents plans.

Un passage explique :

> « Une substance ne possède pas les mêmes propriétés selon le monde dont elle est issue. Comprendre l'origine planaire d'une matière est donc indispensable à toute alchimie avancée. »

Le livre contient ensuite plusieurs chapitres sur :

- les matériaux provenant du Plan Élémentaire du Feu ;
- les plantes du Feywild ;
- les minerais provenant du Plan Élémentaire de la Terre ;
- les propriétés de substances originaires d'autres plans.

➡️ **Ce livre va avec 🌐 la Sphère.**

### Rencontre

L'équipe des Arcanes est particulièrement à l'aise.

et finit l'epreuve au moment ou les joueurs arrivent dans la salle, ils quittent donc la salle et disent au joueurs de se méfier

### Récompense

- Bonne réponse : **+15**
- Mauvaise réponse : -10

# 6. Salle de la Mémoire

### Salle réservée aux joueurs

Une pièce vide.

Sur les murs apparaissent progressivement des scènes représentant les joueurs.

Certaines semblent représenter des souvenirs qu'ils ne possèdent plus.

La pièce ne donne aucune explication.

### Épreuve

Chaque joueur doit choisir une scène.

Lorsqu'il touche l'image, celle-ci disparaît.

Une autre apparaît.

Les joueurs doivent comprendre qu'ils doivent **choisir les souvenirs qui semblent réellement leur appartenir**.

### Particularité

Les images ne donnent pas de véritable souvenir important.

Elles servent surtout à créer une atmosphère et à rappeler la problématique centrale de la campagne.

### Récompense

Si les joueurs comprennent rapidement le fonctionnement :

**+10 points.**

# Structure idéale

Le labyrinthe ne doit pas être un parcours linéaire.

Il devrait proposer plusieurs chemins :

**Entrée**  
→ Salle commune  
→ choix entre 2 ou 3 chemins  
→ Salle d'académie  
→ salle neutre  
→ possibilité de rejoindre une autre équipe  
→ raccourci / piège  
→ salle finale  
→ **Sortie**

Les joueurs doivent avoir le choix de foncer vers la sortie ou de faire des épreuves pour gagner des points
