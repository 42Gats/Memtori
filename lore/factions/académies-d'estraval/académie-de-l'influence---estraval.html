Académie de l'Influence - Estraval

Académie de l'Influence - Estraval

Aug 28, 202610 min read

Résumé

L’Académie de l’Influence est l’une des institutions les plus importantes d’Estraval.

Contrairement aux académies spécialisées dans la destruction, la transformation ou la création, elle étudie principalement les magies permettant d’améliorer, protéger et restaurer les êtres vivants.

Elle regroupe les principaux spécialistes de la magie de soin et de soutien de la cité.

L’académie possède notamment le plus grand hôpital magique d’Estraval, où sont traitées aussi bien les blessures ordinaires que les traumatismes causés par la magie.

Ses étudiants sont formés pour devenir :

  • soigneurs ;
  • médecins arcaniques ;
  • mages de soutien ;
  • guérisseurs de terrain ;
  • spécialistes de la purification ;
  • experts en renforcement magique.

L’académie est particulièrement respectée par les autres institutions.

Même les mages les plus arrogants d’Estraval doivent un jour faire appel à ses services.

Informations générales

  • Type : Académie de magie et hôpital universitaire
  • Spécialisation : Soins, protection et soutien
  • Ville : Estraval
  • Statut : Académie majeure
  • Réputation : Exceptionnelle
  • Domaine principal : Magie de restauration et d’amélioration
  • Relation avec les autres académies : Excellente

Philosophie

La devise de l’académie est :

« La plus grande puissance est celle qui permet aux autres de continuer à se battre. »

L’académie considère que la magie ne doit pas uniquement servir à vaincre un adversaire.

Un mage capable de sauver dix personnes est parfois plus précieux qu’un mage capable d’en tuer cent.

Les étudiants apprennent donc trois principes fondamentaux :

  • Préserver : empêcher une personne de mourir.
  • Restaurer : réparer ce qui peut encore l’être.
  • Renforcer : permettre à une personne de dépasser temporairement ses propres limites.

Les professeurs insistent également sur un principe essentiel :

« Un bon soigneur ne cherche pas à empêcher toute blessure. Il cherche à faire en sorte qu’une blessure ne devienne jamais une mort. »

Domaines d’enseignement

L’académie étudie principalement les magies permettant d’améliorer l’état d’une créature.

Soins

Les étudiants apprennent à utiliser la magie pour traiter :

  • les blessures ;
  • les brûlures ;
  • les fractures ;
  • les hémorragies ;
  • les traumatismes internes ;
  • certaines maladies ;
  • les blessures magiques.

Les sorts de soin constituent la base de la formation.

Restauration

Cette branche concerne les blessures ou altérations plus complexes.

Les étudiants apprennent notamment à traiter :

  • les poisons ;
  • les malédictions ;
  • les maladies magiques ;
  • les paralysies ;
  • certains effets mentaux ;
  • les handicaps temporaires ;
  • les dégâts causés par certains artefacts.

Les sorts les plus puissants sont réservés aux étudiants avancés et aux médecins expérimentés.

Renforcement

Cette branche est consacrée aux buffs.

Les étudiants apprennent à améliorer temporairement les capacités d’une personne.

Ils peuvent notamment renforcer :

  • la force ;
  • la constitution ;
  • la vitesse ;
  • les réflexes ;
  • la concentration ;
  • la résistance magique ;
  • les capacités physiques ;
  • les capacités mentales.

Ces sorts sont particulièrement utilisés par les aventuriers et les militaires.

Formations

Soigneur arcanique — 3 ans

Formation fondamentale de l’académie.

Les étudiants apprennent :

  • les sorts de soin ;
  • l’anatomie ;
  • les premiers secours ;
  • la stabilisation magique ;
  • la gestion des blessures ;
  • l’identification des maladies ;
  • la gestion des urgences.

Les meilleurs étudiants peuvent intégrer l’hôpital universitaire.

Médecin arcanique — 5 ans

Formation avancée.

Les étudiants étudient les interactions entre :

  • magie ;
  • corps ;
  • âme ;
  • maladies ;
  • blessures surnaturelles.

Ils peuvent ensuite se spécialiser dans différentes disciplines.

Soutien de combat — 3 ans

Formation destinée aux mages accompagnant les soldats et aventuriers.

Les étudiants apprennent à :

  • soigner sous pression ;
  • protéger leurs alliés ;
  • renforcer leurs capacités ;
  • maintenir une équipe en état de combattre ;
  • retirer les altérations ;
  • stabiliser un combattant gravement blessé.

Les étudiants de cette formation participent régulièrement à des exercices avec l’Académie de l’Evocation - Estraval.

L’Hôpital Universitaire

L’une des particularités de l’académie est son immense hôpital.

Il s’agit du principal établissement médical d’Estraval.

Il accueille :

  • les habitants ;
  • les étudiants ;
  • les chercheurs ;
  • les militaires ;
  • les aventuriers ;
  • les victimes d’accidents magiques.

L’hôpital est également un lieu d’enseignement.

Les étudiants ne se contentent pas d’apprendre la théorie.

Ils travaillent directement auprès des patients sous la supervision de médecins expérimentés.

Les urgences arcaniques

Les urgences sont constamment surveillées.

Elles accueillent notamment les victimes :

  • d’expériences magiques ;
  • d’explosions ;
  • de combats ;
  • d’accidents de téléportation ;
  • de créatures surnaturelles ;
  • d’artefacts dangereux.

Les étudiants les plus expérimentés peuvent être appelés en renfort lorsque plusieurs patients arrivent simultanément.

La Salle de Restauration

Une section spécialisée dans les blessures particulièrement graves.

Elle possède plusieurs cercles magiques permettant d’accélérer les soins.

Certains patients peuvent y être maintenus artificiellement en vie pendant plusieurs jours.

La Chambre des Purifications

Une salle extrêmement protégée.

Elle est utilisée pour traiter :

  • les malédictions ;
  • les poisons ;
  • les maladies magiques ;
  • les corruptions surnaturelles.

Les patients y sont isolés afin d’éviter toute contamination.

Les salles d’entraînement

La Salle des Blessures

Une salle permettant de reproduire artificiellement différents types de blessures.

Les étudiants doivent identifier rapidement :

  • la nature du traumatisme ;
  • sa gravité ;
  • le traitement nécessaire.

Certaines blessures sont créées magiquement afin de reproduire les effets de sorts ou de créatures particulières.

La Salle du Dernier Souffle

Une salle dédiée aux situations d’urgence.

Des illusions magiques reproduisent des situations dans lesquelles plusieurs personnes sont gravement blessées.

Les étudiants doivent décider rapidement :

Qui soigner en premier ?

L’objectif n’est pas uniquement d’apprendre à soigner.

Il s’agit également d’apprendre à prendre des décisions sous pression.

Le Pavillon des Renforcements

Une vaste salle utilisée pour tester les sorts de buffs.

Les étudiants peuvent mesurer précisément les effets de leurs sorts sur des volontaires.

Des instruments magiques permettent de mesurer :

  • la force ;
  • la vitesse ;
  • les réflexes ;
  • la résistance ;
  • la concentration ;
  • la puissance magique.

Le corps enseignant

Les professeurs sont généralement d’anciens médecins arcaniques ou des mages de soutien ayant participé à de nombreuses expéditions.

Ils sont réputés pour être beaucoup plus patients que les enseignants des autres académies.

Cependant, ils peuvent se montrer extrêmement stricts lorsqu’un étudiant met volontairement un patient en danger.

Une erreur médicale est considérée comme une occasion d’apprendre.

Une erreur provoquée par négligence est beaucoup plus sévèrement sanctionnée.

Le directeur

Le directeur de l’académie est également le responsable de l’hôpital universitaire.

Il possède une immense expérience dans les domaines de la restauration et de la protection magique.

Contrairement aux directeurs de certaines académies, il n’est pas particulièrement intéressé par la gloire.

Son principal objectif est de former suffisamment de spécialistes pour que personne à Estraval ne meure simplement parce qu’il n’y avait personne capable de le soigner.

Il entretient de bonnes relations avec la plupart des autres directeurs.

Relations avec les autres académies

Académie de l’Evocation - Estraval

Respect mutuel et rivalité.

Les deux académies ont des philosophies très différentes.

L’Évocation apprend à ses étudiants à infliger des dégâts.

L’Influence leur apprend à empêcher ces dégâts de tuer quelqu’un.

Les étudiants de l’Évocation plaisantent régulièrement en disant :

« Ils existent uniquement parce que nous faisons exploser des choses. »

Les soigneurs répondent généralement :

« Et nous sommes très heureux que vous financiez notre hôpital. »

Malgré les plaisanteries, les deux académies collaborent énormément.

Académie de l’Altération- Estraval

Excellente coopération.

Les altérateurs travaillent régulièrement avec les médecins arcaniques sur les interactions entre :

  • corps ;
  • espace ;
  • temps ;
  • magie de restauration.

Les recherches sur la téléportation et les blessures dimensionnelles nécessitent notamment leur coopération.

Académie de l’Ingénierie Arcanique

Partenaire privilégié.

Les deux académies entretiennent une coopération constante autour de la médecine magique et de la création d’équipements destinés aux soins.

L’Ingénierie Arcanique fournit notamment :

  • potions ;
  • médicaments ;
  • antidotes ;
  • composants médicinaux ;
  • stimulants ;
  • dispositifs médicaux ;
  • prothèses enchantées ;
  • outils permettant de surveiller les patients ;
  • équipements permettant de stabiliser les blessés.

L’Académie de l’Influence - Estraval fournit en retour les connaissances médicales et magiques nécessaires pour tester ces produits et équipements, ainsi que pour développer de nouveaux traitements.

Une grande partie des équipements utilisés dans l’hôpital universitaire d’Estraval est ainsi issue de cette collaboration.

Académie des Arcanes - Estraval

Relations cordiales.

Les chercheurs des deux académies travaillent notamment sur l’histoire des anciennes techniques médicales et les méthodes de guérison oubliées.

Le tournoi des académies

L’Influence n’est généralement pas l’académie qui domine le classement général.

Elle est cependant particulièrement redoutable dans les épreuves nécessitant :

  • coopération ;
  • endurance ;
  • protection ;
  • sauvetage ;
  • défense d’objectifs ;
  • survie.

Ses équipes sont souvent capables de continuer à combattre alors que les autres commencent à manquer de ressources.

Une équipe d’Évocation peut éliminer rapidement ses adversaires.

Une équipe d’Influence peut parfois survivre suffisamment longtemps pour retourner complètement la situation.

Identité des étudiants

Les étudiants de l’Influence sont généralement considérés comme les plus coopératifs d’Estraval.

Ils travaillent souvent en groupe et développent rapidement une forte solidarité.

Cependant, la formation est difficile.

Un étudiant doit apprendre à rester calme face à :

  • un patient mourant ;
  • plusieurs blessés simultanément ;
  • un allié paniqué ;
  • une situation de combat ;
  • une magie inconnue.

Les meilleurs étudiants développent une capacité impressionnante à garder leur sang-froid.

Ce que les joueurs peuvent y faire

Les joueurs peuvent :

  • se faire soigner ;
  • acheter des potions ou médicaments ;
  • apprendre des sorts de soin ;
  • apprendre des sorts de soutien ;
  • obtenir des buffs temporaires ;
  • faire identifier une blessure magique ;
  • faire retirer une malédiction ou un poison ;
  • demander l’aide d’un médecin arcanique ;
  • participer à des expériences médicales ;
  • recruter un mage de soutien ;
  • obtenir une recommandation académique ;
  • participer au tournoi des académies ;
  • rechercher des informations sur certaines formes de magie.

L’académie peut également fournir aux joueurs un soin particulièrement puissant en échange d’un service, d’une recherche ou d’une aide apportée à l’hôpital.

Notes MJ

L’Académie de l’Influence doit être présentée comme le cœur médical d’Estraval.

Elle permet de montrer un aspect important de la cité : la magie n’y sert pas uniquement à combattre ou à produire de l’énergie. Elle est également devenue une véritable science médicale.

L’hôpital doit être particulièrement impressionnant pour les joueurs venant de cités moins avancées.

Un personnage gravement blessé dans une autre cité pourrait nécessiter plusieurs jours de repos.

À Estraval, un médecin arcanique peut simplement poser ses mains sur lui et commencer à reconstruire progressivement ses tissus.

L’académie constitue également un bon endroit pour montrer les limites de la magie.

Tout ne peut pas être soigné.

Certaines blessures nécessitent plusieurs jours, certains effets magiques sont irréversibles et certaines altérations dépassent même les connaissances des meilleurs médecins d’Estraval.

Cela permet d’éviter que la présence de puissants sorts de soin rende les blessures ou les conséquences des combats insignifiantes.

Enfin, l’académie peut devenir particulièrement importante pour les personnages confrontés aux conséquences de la magie mémorielle. Ses spécialistes connaissent les effets généraux des altérations mentales et pourraient identifier certains symptômes sans nécessairement être capables de réparer les dégâts causés par Maltherion Veyrith.
